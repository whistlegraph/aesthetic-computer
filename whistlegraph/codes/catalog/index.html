What you are collecting. Each token is the whistlegraph's code — the registry entry of the work itself. The 2022 Feral File video editions (Dutch auction, $1,480.80 base) remain distinct historical artifacts; ten unsold editions returned to whistlegraph.eth in 2026 and are held in reserve, never for fire-sale.

Funding codes. When Whistlegraph Dot Org releases music derived from a graph, the holder of its code receives the first edition and a 20% split of primary mints and resale royalties. Patronage, not investment; no return promised.

Colored cards mark works whose score frame is still being extracted from the original performance — the drawing's final frame is the score, and each card carries the work's registry color until it lands.
