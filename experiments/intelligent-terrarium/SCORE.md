# Score for Piecefarm / Sort Soup

`jas-nzxt` is the Piecefarm. The upper display is its observatory board. The
lower display is its living program population.

The founding population inhabited the sorting type

```text
Vector<Int,n> -> SortedPermutation<Int,n>
```

The live population now also inhabits the bounded media type

```text
PixelGroove<160,RGB24,v1> -> RGBField<Q|H|1X|2X,u8>
```

This is not a claim that the JavaScript verifier implements dependent type
theory. These are executable contracts checked by the reference evaluator:
sort output must preserve the multiset, while a raster program must stay within
its recorded field, instruction, operation, allocation, and protected-margin
budgets.

## Performance cycle

1. Derive a bounded Lisp form from persisted PRNG state and synchronized AC UTC.
2. Resolve it into the current sorting or raster language and hardware profile.
3. Execute it on the deterministic verification suite.
4. Reject any output that is not sorted or is not a permutation.
5. Measure the actual comparison, write, swap, locality, and recursion trace.
6. Place the behavior in the novelty archive.
7. Press a verified raster candidate into a fixed PixelGroove record.
8. Execute every addressed record continuously in the native margin VM and
   project its temporal memory volume, rather than drawing a decorative icon.
9. Retain a candidate only when it opens a behavioral niche or improves its resident.
10. Accept outside LLM/prox candidates only through the proposal membrane.

## Safety rule

Outside models propose Lisp. They never receive a shell, an arbitrary network
capability, a raw pointer, or authority to mutate the archive directly. A
proposal is bounded, provenance-logged, parsed, checked, and executed by the
same reference path as every grammar mutation.

## Display contract

- **Top / board:** large source, selection, novelty, coverage, verification,
  resource behavior, origin, lineage, checkpoint countdown, and measured
  display rate.
- **Bottom / soup:** twelve fixed-address native organisms. Each tile is the
  real 128² presentation membrane around a Q/H/1X/2X field and its actual
  PixelGroove margin. An eight-slice temporal volume is projected through
  resident camera/algebra cells as curved, ray, chamber, or height space. The
  blinking needle is the live reader address. Small corner, HP, operation, and
  console marks are telemetry rather than a decorative explanatory panel.
- Both panels are halves of one native SDL3 stage spanning the detected
  2560 × 2880 desktop. They draw into contiguous 640 × 360 CPU framebuffers
  with AC-OS's embedded MatrixChunky8 glyphs, upload one 640 × 720 streaming
  textures, and scale 4× with nearest-neighbor sampling. A geometry watchdog
  restores the union bounds and stacking order. Chromium is not in the display
  path. Frame pacing follows the slower detected display mode rather than a
  fixed browser timer. Search state is sampled into the visible population at
  one-second intervals, while native VM fields, projections, reader needles,
  and HP bars continue independently.

## Live memory and sound

Each addressed resident owns one fixed 27,648-byte margin record, mutable
reader/fringe/sprite tracks, and one profile-sized field. The reader executes at
240 virtual slots/second. Projection algebra is bounded, verified, and promoted
from quarantined candidate bodies; perspective camera matrices and projection
generation live in the record's otherwise untouchable computational margin.

Musigraph reads resident memory into smoothed 64-sample wavetables. AC UTC and
60 BPM define eighth/quarter-note time; field energy, variance, spatial energy,
life state, grid position, and listener distance determine pitch, texture,
amplitude, percussion, and equal-power stereo pan. The live spectrum and active
projection family are measured back onto the top board.

Every 2,048 admitted evaluations creates a local Git edition containing only
`archive.json` and `edition.json`. Mutable Groove state rotates back through the
loopback authority before checkpoints, so Git history preserves lived reader
state rather than merely regenerating organisms from source.

## Next ecological niches

Sorting is the founding verifier, not the farm's permanent ontology. Add
families whose effects remain complete and cheap to record:

1. cellular automata and reaction/diffusion rules;
2. graph rewriting, lambda reduction, SK combinators, and register machines;
3. exact integer sequences, modular systems, continued fractions, and small
   Diophantine searches;
4. pathfinding, spanning trees, union-find, flood fill, packing, and constraint
   propagation;
5. compression, suffix automata, L-systems, and grammar induction; and
6. type-inhabitant search and proof-term normalization for the typed Lisp core.

Every niche supplies its own verifier and behavior descriptor. Every execution
also emits an effect ledger: reads, writes, allocation/high-water memory,
emitted pixels and sound events, steps, termination, verifier result, and
lineage. MAP-Elites retains quality per occupied cell; active novelty remains a
separate distance from occupied behavior cells. No novelty score grants file,
network, shell, or device authority.

## Honest current limits

- The Lisp is a bounded raster/sorting language, not general KidLisp,
  self-hosted Lisp, homotopy type theory, or arbitrary native code.
- Verification is deterministic reference execution plus properties and
  protected-record hashes, not a proof-producing cubical type checker.
- Evaluation remains JavaScript. Native execution is a fixed interpreter; it
  does not pretend to be a verified self-JIT.
- Novelty uses hand-chosen behavioral niches. HP measures runtime viability and
  deliberately excludes aesthetic preference.
- Eight CPU workers and a deterministic 64-proposal window currently sustain
  roughly 45–51 mixed-resolution evaluations/second. Ordered admission makes
  worker-count replay identical, but window tails still leave some CPU idle.
- OpenAI vision reviews only high-change, low-noise retained fields. Its bounded
  tags and recommendation enter specimen metadata and board telemetry; they do
  not directly kill an organism or overwrite HP.
- The RTX 3070 is occupied by the independent miner. Piecefarm uses it for SDL
  presentation only; GPU search has no coexistence authority.
- The API is intentionally loopback-only, and the dedicated Loopboy is the
  caretaker/proposal route. Xbox/web visitation is still a later access gate,
  not a public service.
