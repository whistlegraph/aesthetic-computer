# Cleared arcade percussion slots

Place release-cleared WAV one-shots here as `accent-1.wav`, `accent-2.wav`, and
`accent-3.wav`, then render with:

```sh
TAKSMUKKE_ARCADE_SAMPLES=pop/teknull/samples/arcade \
  sh pop/teknull/c/render-taksmukkeklokken.sh
```

These files are used only as sparse percussion at section transitions. Missing
slots render as original synthesized arcade impacts. Do not add ripped game
audio without written clearance from its rightsholder.
