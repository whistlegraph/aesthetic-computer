# Special Sign 720

A six-minute, 72-to-144 BPM dance/trance remix of the locked Special Sign
master. The name describes the hinge of the arrangement: a patient 72 BPM
build opens into its 144 BPM double-time pop pulse at exactly 2:00.

The orchestration stays intentionally small: the original spatial field, one
sub-bass voice, kick, clap, hats, and a single C-major trance pulse. This is an
isolated variant and never writes into `release/special-sign/`.

Render from the repository root:

```sh
node pop/nullabye/variants/special-sign-720/render.mjs
```

Outputs are written beneath
`pop/nullabye/out/review/variants/special-sign-720/` as a 24-bit/48 kHz WAV,
cover-tagged 320 kbps MP3, and a provenance receipt.
