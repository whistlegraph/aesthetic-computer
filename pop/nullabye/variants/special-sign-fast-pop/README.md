# Special Sign — Fast Pop / Chopped + Screwed Fork

Exploratory 148 BPM dance arrangement derived from the dry-leaning Special Sign
audition. This variant is deliberately isolated from the locked release and the
near-final mastering scripts.

Render from the repository root:

```sh
node pop/nullabye/variants/special-sign-fast-pop/render.mjs
```

The renderer creates a 24-bit/48 kHz WAV, 320 kbps listening MP3, and provenance
receipt beneath `pop/nullabye/out/review/variants/special-sign-fast-pop/`.
