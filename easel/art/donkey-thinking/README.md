# Thinking poses

Eight colored-pencil donkey poses for the notebook companion: attentive, listening,
pondering, head down, reconsidering, looking up, realization, relaxed.

Generated with the built-in imagegen tool on September 21, 2026, using
`shared/assets/donkey-pencil-run-v2.png` as the character/style reference.
The exact prompt is in `prompt.txt`; the generated RGBA sheet is preserved as
`shared/assets/donkey-pencil-thinking-v1.png`. Four equal columns, two rows;
no runtime image generation. Listening and thinking use slower held poses;
writing/tool activity keeps the existing running cycle. Reduced motion holds
one frame; hidden windows stop timers.
