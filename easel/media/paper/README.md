Portable /papers lane: archival LaTeX, explicit user byline, bibliography,
consulted-source log, numbered figures, embedded text-source ZIP, and hash-bound
visual QA. A compiling PDF is built-awaiting-qa, never automatically ready.

The source-bundle style and Aesthetic Eye validator are copied from the AC
papers stack. No private Platter materials, studio fonts, author identity, or
local Paper MCP service are required. Tectonic or XeLaTeX/BibTeX is optional
host software. User manuscripts use the supported LaTeX subset; shell commands,
external inputs, arbitrary packages, and macro definitions are excluded.

Only manuscript.tex, references.bib, ac-source-bundle.sty and an inventory are
embedded. sources.md and figure binaries are deliberately excluded from that
public attachment. Figures remain in the artifact for local reproducibility.
