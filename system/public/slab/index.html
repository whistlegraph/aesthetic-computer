slab

slab

A desk for running many coding agents at once.

A macOS menu bar app from Aesthetic Computer. Every Claude Code, Codex or Easel session on the machine gets a colour, a name, a stone, and a place on the wall.

blueberry, a tuesday night. six panes, five rocks, one easel. the text is blurred; everything else is real.

what you're looking at

The colour is the state.

Each terminal is re-skinned by the session inside it: one tint while the agent works, another when it stops to ask you something, a third when the turn is done. From across the room you know which pane wants you.

The title is the task.

Slab reads the transcript and titles the window with what the session is doing, so the Window menu reads like a to-do list instead of six copies of bash.

The stone is the session.

Top-right of every pane, a prompt rock. It spins while the agent works, slows when it is waiting, and carries a pet name so you can say "poke veguri" out loud.

The grid is one keystroke.

⌘⌥T tiles every agent terminal into a wall. ⌘⌥S scatters them again. Easel sessions get a live preview of the piece they are making, pinned to their own pane.

prompt rocks

One rock per live prompt.

Its shape grows from the session and the prompt in flight, so the stone re-forms when the work moves on. Its motion is the status channel: spin speed and direction say working, awaiting, complete, and a poke from another session makes it blink and rattle. It carries a pet name in bubble letters. Pointing at a rock wakes a small seeded percussion voice; clicking it reveals what the session has done so far. Sweep across the wall and the rocks are a tiny drum kit.

An Easel rock is also a code. Point a phone at it and the piece that session is making opens on the phone.

walking the wall

Slab holds a few global shortcuts. They all work whether or not the menu is open.

  • ⌘⌥T Tile the agent terminals into a grid.
  • ⌘⌥S Scatter them back into loose windows.
  • ⌘⌥← ⌘⌥→ ⌘⌥↑ ⌘⌥↓ Move focus across the wall spatially. At the edge of the screen it keeps going onto the next Mac, if there is one.
  • ⌘⌥ held A small arrow pad appears over the focused pane, each key lit with the colour of the pane it would land on. Hollow keys point at another machine.
  • ⌘⌥X Keyboard focus on the rocks themselves. Escape lets go.
  • ⌃⌥⌘A Dark mode, on this Mac and every other Mac running Slab.

the ear's version

Three short cues, synthesized so they share one voice and differ only in contour. You learn to tell them apart without looking up.

complete · two notes falling a third. A resolve: "done".
awaiting · three notes climbing a triad. A question: "you?"
disconnected · one tone sliding down an octave, with a beat in it. "gone".

where it came from

Slab started in April 2026 as a sleeping laptop. Close the lid while an agent is still working and the Mac plays a slow pentatonic bed through its own speakers, answers claps and hums with little pluck arpeggios, and puts itself to sleep with a chime when the last job finishes. The name is from that: a closed MacBook on a desk, humming.

The lid daemon is still in the box. The menu bar grew around it once the sessions multiplied and one laptop became four Macs on one desk.

one menu bar on every mac

Each Mac in the studio runs the same Slab. They share a ledger of live sessions over the tailnet, so an agent on one machine can name a session on another as host:name and find it instantly. A frame is a picture of any desk with its text and buttons located; a puppet acts on what the frame saw. Rocks stay local. A machine never draws another machine's stones.

getting it

Slab is not packaged yet.

There is no download, no App Store listing, no one-line installer. It lives inside the Aesthetic Computer monorepo and is built from source on each Mac. If that does not put you off:

git clone https://github.com/whistlegraph/aesthetic-computer.git
cd aesthetic-computer/slab
./install.sh --prompt-host        # hooks + session markers; no audio, no sudo
./menubar-swift/install.sh        # builds and launches the menu bar

It wants macOS on Apple silicon, the Xcode command line tools, and Claude Code. Codex and Easel sessions are tracked too. The installer merges hooks into ~/.claude/settings.json, installs a launchd agent, and asks for Accessibility so it can move Terminal windows. Screen Recording is only requested the first time something asks for a frame. ./uninstall.sh takes it all back out.

The lid ambient, the fleet ledger and the multi-Mac navigation are tuned to one studio's machines right now. Expect to read a shell script or two. A build you can just download is the next thing, and interest is what moves it up the list.
