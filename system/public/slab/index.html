Install & shortcuts

Drag Slab to Applications and open it. Allow Accessibility when prompted so it can move windows. The first-run dialog offers to add Claude Code hooks; it backs up your settings first.

⌘⌥T tile · ⌘⌥S scatter · ⌘⌥←↑↓→ move between windows · ⌘⌥X focus rocks.

Screen Recording is requested only when you capture a frame. Multi-Mac features need separate setup.
