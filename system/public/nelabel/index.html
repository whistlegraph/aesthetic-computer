nela bel sampler

If you've got a track you'd want on it, drop a sampler. 16 seconds of it, any section you like. wav or flac if you can, a phone recording is fine too.

Anyone who drops a clip is on the sampler. The full release is whoever finishes. The clips get stitched into one preview so we can hear it as a whole.
