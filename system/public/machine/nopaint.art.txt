# No Paint

> Make paintings by accepting or rejecting proposed moves, with classic and AI tools.

Classic tools run without an account. Cloud models require an Aesthetic Computer account and braincells.

## Resources

- [Website](https://nopaint.art/): Public entry point.
- [Classic app](https://nopaint.art/classic): Preserved earlier application.
- [Gallery](https://nopaint.art/gallery/): Public painting records.
- [Gallery JSON](https://nopaint.art/gallery/gallery.json): Public gallery data used by the gallery page.

## Network

- [Aesthetic Computer machine directory](https://aesthetic.computer/network.json): Public properties, descriptions and machine entry points.
