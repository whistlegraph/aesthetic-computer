# Learn KidLisp

> Language lessons and examples for KidLisp.

## Resources

- [Website](https://learn.kidlisp.com/): Public entry point.
- [Editor](https://kidlisp.com/): Try a program.

- [Piece runtime API (JSON)](https://aesthetic.computer/docs.json): JavaScript lifecycle, drawing, audio, input and piece metadata.
