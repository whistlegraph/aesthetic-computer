Menu Band on Windows 11

Setting up a Windows 11 Pro build machine, and whether the tiny piano could live in the taskbar. October 2026.

Step 1: let neo in over SSH

Windows 11 Pro ships the OpenSSH client but not the server. The usual Add-WindowsCapability route pulls from Windows Update and can hang for minutes with no output, so this installs the same server from Microsoft's GitHub release through winget instead. Right-click Start, open Terminal (Admin), paste all of this, press Enter:

winget install Microsoft.OpenSSH.Preview --accept-package-agreements --accept-source-agreements
Start-Service sshd
Set-Service -Name sshd -StartupType Automatic
New-NetFirewallRule -Name sshd -DisplayName 'OpenSSH Server (sshd)' -Enabled True `
  -Direction Inbound -Protocol TCP -Action Allow -LocalPort 22 -Profile Any
New-ItemProperty -Path "HKLM:\SOFTWARE\OpenSSH" -Name DefaultShell `
  -Value "C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe" -PropertyType String -Force
(Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.InterfaceAlias -notmatch 'Loopback' }).IPAddress

The last line prints the machine's IPv4 address. Hand that to Claude on neo, and the rest of the build-machine setup (keys, git, cmake, Python, Visual Studio Build Tools) happens over SSH. For an administrator account, public keys go in C:\ProgramData\ssh\administrators_authorized_keys, not the home folder.

Step 2: check it from the Mac

ssh js@<that address>

Why a Windows machine at all

Verdict. Buildable. The sound, the MIDI, and the typing all port, and some of it gets easier. The piano strip in the taskbar is the one part Microsoft gives you no supported way to do, so it would ship as an overlay window that follows the taskbar around.

The taskbar piano

  • No supported API. Windows 10 had deskbands, the mechanism for putting a custom strip inside the taskbar. Windows 11 removed them and has shipped no replacement through 25H2. Microsoft's own answer is "use a third-party tool", which they also say they don't support. The sanctioned surface is a 16-pixel tray icon plus a flyout on click. That is the popover, not the strip.
  • The route that works is an overlay window. A borderless, always-on-top, non-activating window placed over empty taskbar space, with a watchdog that follows the taskbar through moves, auto-hide, full-screen apps and monitor changes. ElevenClock, StartAllBack and RoundedTB all ship this way to large user bases. The window receives hover and mouse events like any other, so hover-to-play survives. It stays a hack a Windows update can jostle, and it sits beside the centered icon cluster rather than inside it.

The cost

The app is about 62,000 lines of Swift, and 89 of its files import AppKit. The DSP ports as is. The shell, the strip renderer, the visualizer and the sheet views are new code. The features the Mac App Store forbids, global typing and system hotkeys, are the easy tier on Windows.
