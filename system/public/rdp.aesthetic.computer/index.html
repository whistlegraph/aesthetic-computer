Radical Digital Painting — metadata host

This host serves the on-chain ERC-721 metadata for Radical Digital Painting, the 239-token contract by Jeffrey Alan Scudder — tokenURI(n) resolves to /json/n.json for tokens 1–239. See the contract on Etherscan, the collection on OpenSea, the painting archive on jas.life, and nft.aesthetic.computer for the full on-chain record.
