Make games in Claude

  1. In Claude Desktop, open Customize → Connectors and add a custom connector.
  2. Name it Aesthetic.Computer. Use https://aesthetic.computer/mcp/ac as its URL.
  3. Connect and sign in with your AC account. Choose a handle first if you need one.
  4. Enable the connector in a chat. Ask: “Read the game guide, check my AC handle, and make a private .oskie game where I catch a moving square.”
  5. Open its preview link in Chrome. Keep the tab open while asking Claude for changes. Claude can inspect screenshots and errors from that tab.
  6. When ready, ask Claude to publish the reviewed game. Share the public link or download the .oskie file.

Draft edits stay private until you publish again. Preview links last 24 hours; anyone with the link can view the draft. Ask Claude for a new preview when one expires.

Ask Claude to restore an earlier revision, unpublish a game, or delete a project and its history. Download a copy before deleting.

.oskie files

Portable game microcode: a JSON bundle of JavaScript modules and assets. Drop one onto Aesthetic Computer or open it in the player. Local files stay in your browser.

The initial AC runtime supports canvas graphics, keyboard, pointer, gamepads and tones. Oskiewar fight overlays, its 3D figures and netplay still need their original engine. Hosted games can contain up to 2 MB and 128 files. The beta allows 100 projects and 200 saved revisions per account.
