Oskiewar so far

Artur’s Island Crisis helped turn Oskiewar into a kit for making other games. He worked with Claude Code, played successive builds, and brought back requests for what the engine should do next.

October 20, 2026 · The kit
Jeffrey shared a workflow with Artur: describe a game in Claude Code, play it locally with live reload, then pack a single .oskie file or publish a web build.
October 21–22 · Island Crisis
Artur built a 3D rail shooter, initially drawing its own 3D with triangles. His requests to use Oskiewar’s characters and props helped drive engine 452: camera controls, reusable objects and procedural figures, with a showroom example.
October 23–26 · Playing and sharing
The work moved between camera scale, shooting, UI overlays and island encounters. The kit gained game-specific titles and generated cover images for sharing. Island Crisis web build ↗
October 27 · A Fuser version
Artur shared Island Crisis by Dreamdealer on Fuser ↗, taking the experiment into another game-making tool.
November 6 · Aesthetic.Computer
The next workflow brings game creation into Claude Desktop with an AC @handle, live browser previews and saved revisions. The .oskie name carries forward. This first AC canvas player does not yet run the original kit’s full 3D API.

The linked games may show later revisions. Island Crisis’s current web build identifies itself as a Three.js game; it is not an archived copy of the October Oskiewar build.
