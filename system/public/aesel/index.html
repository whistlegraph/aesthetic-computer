Aesel

Easily make and share new media. Describe a piece; a brain writes it; it plays live on your phone and publishes to your @handle on Aesthetic.Computer.

Install

Aesel TUI. The terminal installer uses your Node.js 22+ or fetches its own. After installing, type a to start.

Mac TerminalLinux
curl -fsSL https://prompt.ac/aesel.sh | sh
Windows PowerShell
irm https://aesel.app/install.ps1 | iex
AC OS
Type aesel at the device prompt. Use link to pair your handle.
AC prompt
Type aesel at the web prompt, or open Aesel TUI.

A session

  1. Start from a blank piece or a nopaint.art brush.
  2. Describe it. The brain writes the code and checks the canvas.
  3. Watch it live on any phone, by QR code.
  4. Keep it. Each save publishes to aesthetic.computer/@you/name; /versions and /rollback keep every one.
