Aesel

Easily make and share new media with Aesel. Describe a piece in plain words. A brain writes it, it plays live on your phone, and it publishes to your @handle on Aesthetic Computer.

A session

  1. Pick a start. A blank Aesthetic Computer piece, or a nopaint.art brush.
  2. Describe it. The brain writes the code and reads the canvas back to check its work.
  3. Watch it. A QR code opens the piece on any phone, and every save arrives there live.
  4. Keep it. Signed in, each save publishes to aesthetic.computer/@you/name. /versions lists them; /rollback adds, never erases.
Fig. 1. A session in the terminal, with the live piece in its frame. Fig. 2. The .p5 piece it made, running on Aesthetic Computer.

Four runtimes

Pick with /runtime or --runtime. All four push live and publish to your @handle.

.mjsAesthetic ComputerJavaScript against AC’s own API: paint, wipe, ink, sound, input, multiplayer.

  wipe("pink");

(wipe "pink")
(ink "yellow")

.p5p5.js (processing)Real p5.js, running inside an AC piece.

  createCanvas(windowWidth, windowHeight);
}

  background(255, 184, 220);
}
.l5L5Aesthetic Computer’s own Processing, in Lua.

  background(255, 184, 220)
  circle(width / 2, height / 2, 64)
end
