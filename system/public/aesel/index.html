Where it sits

Aesel is the part of Aesthetic Computer you talk to. It holds the conversation and the files; an engine does the writing; Aesthetic Computer runs and keeps what you make.

  1. youa prompt“a starfield that warps when I press”
  2. aeselthe harnessterminal · Mac · Windows · browserasks an engine: AC hosted, Claude, Codex or OpenRouter
  3. your filea piece.mjs .lisp .p5 .l5every save is a version on your machine
  4. liveyour phonescan the QR; each save plays as it landsand in Slab’s preview beside the terminal
  5. aesthetic.computer@handle/namepublished on every save, signed inpost anything else to mime.ac

A session

  1. Pick a start. A blank Aesthetic Computer piece, or a nopaint.art brush.
  2. Describe it. Plain words. The engine writes the code and reads the canvas back to check its work.
  3. Watch it. A QR code opens the piece on any phone, and every save arrives there live.
  4. Keep it. Signed in, each save publishes to aesthetic.computer/@you/name. /versions lists them; /rollback adds, never erases.

Four runtimes

Pick with /runtime or --runtime. All four push live and publish to your @handle.

.mjs

Aesthetic Computer

JavaScript against AC’s own API: paint, wipe, ink, sound, input, multiplayer.

function paint({ wipe }) {
  wipe("pink");
}
export { paint };
.lisp

KidLisp

AC’s small Lisp for generative art — a whole piece in a line.

(wipe "pink")
(ink "yellow")
(circle 128 128 64)
.p5

p5.js processing

Real p5.js, the Processing most people already write — running inside an AC piece.

function setup() {
  createCanvas(windowWidth, windowHeight);
}
function draw() {
  background(255, 184, 220);
}
.l5

L5

Aesthetic Computer’s own Processing, in Lua.

-- moss
function draw()
  background(255, 184, 220)
  circle(width / 2, height / 2, 64)
end

What it makes

Pieces are the heart of it. /medium turns the same conversation toward other kinds of work.

mediumformatswhat you get
pieceapplication/javascript text/x-lisp .p5 .l5a live, published Aesthetic Computer piece
brushapplication/javascripta nopaint.art brush; the painting, undo and zoom come with it
pictureimage/png image/jpeg image/webpa layered 512 × 512 picture; each accepted change adds a layer
soundaudio/wav audio/mpeg audio/ogga score on a shared beat grid, synthesized
paperapplication/pdf text/plainan archival LaTeX paper with its source inside
Game Boyapplication/x-gameboy-roma real ROM, built and checked, playing in AC’s emulator

Anything up to 8 MiB can go to mime.ac under your @handle: aesthetic mime file "caption".

Engines

AC hosted Nothing to install. Paid in braincells on your @handle; the first launch starts here.

Claude · Codex Bring your own subscription through its CLI.

OpenRouter Bring your own key for open models.

Switch any time with /backend and /model. Outside a piece, Aesel is a general harness that runs with your own settings, skills and MCP servers.

Install on Mac

Drag Aesel to Applications, open it, and sign in with your Aesthetic Computer account.

aesel opens the app from a terminal. a runs the harness in the terminal.

Install on Windows

Run the installer, open Aesel, and sign in with your Aesthetic Computer account in your browser. Requires Microsoft WebView2 Runtime.

This beta uses the hosted engine; Claude and Codex are not included. The installer is unsigned, so Windows may show an unknown-publisher or SmartScreen notice.

Install in a terminal

curl -fsSL https://prompt.ac/aesel.sh | sh installs the harness and links a, ac and aesel. /update brings it up to date from inside.

Conversation context goes to the engine that generates your work. Pieces publish to your @handle; notebooks and versions stay on your device. Privacy policy
