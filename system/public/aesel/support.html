Aesel support

Email mail@aesthetic.computer for help. Include your Aesel TUI version and operating system, and what happened. Please leave passwords, tokens, and private conversations out of your report.

Getting started

Use the Aesel TUI installer for your terminal, then type a. At the Aesthetic Computer OS or web prompt, type aesel.

Terminal support

In Mac Terminal, Linux or Windows PowerShell, run a --version to check which release opens. Run a doctor to check the runtime and account. If PowerShell still finds an older launcher, open a new window and run Get-Command a to see its path.
