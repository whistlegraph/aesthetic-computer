sleuth·source index

Search mechanisms, online databases, browser skills, and collection routes for the research platter. A result is a lead until the primary page or file is opened and its stable identifier is recorded.

routing rule

Choose the narrowest primary source. Search it directly when general web indexing is incomplete. Use browser inspection for visual or interactive state. Keep private-vault credentials and unreviewed private paths out of published notes.
