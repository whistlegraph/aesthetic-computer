# Photorealistic theme

Original miniature photography recovered from Neo’s Xbox/AC OS implementation on 2026-09-25. Generation prompts and source hashes are preserved in the provenance files. Browser integration uses the original master PNGs and atlas coordinates; images are decoded once and reused for existing game poses and surfaces.

The website defaults to this theme. `?graphics=flat` selects the vector look. If the background or puppet atlas fails to load, the game uses the vector renderer.
