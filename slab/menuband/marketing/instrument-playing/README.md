# Menu Band — instrument-playing film

The prototype opens with Jeffrey saying “Double tap Command for Menu Band,”
showing two quick live Command-key highlights before teaching one thing: an
ascending C-major scale. It uses Menu Band's real headless AppKit menu-bar,
QWERTY-map, and music-staff renderers, all synchronized to the played notes.

No percussion, radio, Spotify, sampling, recording, or hardware MIDI appears.

```sh
node render-prototype.mjs
```

The final pass uses the established AC vertical reel chrome: 1080×1920 with
audio-reactive Pals and `MenuBand.app` side titles.

Output lands in `out/menu-band-command-scale-instagram-reel-v9.mp4`.
