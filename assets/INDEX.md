## Pushing

Spaces on sfo3 will exit 0 while silently stranding files under the
default 10-way concurrency, so large pushes go at 3 and get counted
afterwards. Private material must carry `--acl private`; the repo's
`assets:sync:up` bakes in `--acl public-read` and must never be reused
for it.

```bash
printf '[default]\ns3 =\n    max_concurrent_requests = 3\n' > /tmp/awscfg/config
AWS_CONFIG_FILE=/tmp/awscfg/config AWS_RETRY_MODE=standard AWS_MAX_ATTEMPTS=10 \
  aws s3 sync <local-dir> s3://assets-aesthetic-computer/private/<area>/<name> \
  --endpoint-url https://sfo3.digitaloceanspaces.com --region sfo3 \
  --acl private --exclude '*.DS_Store'

node toolchain/assets/sync-index.mjs   # then re-register
```
