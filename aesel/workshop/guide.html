Harness Factory

Students write a small tool that takes something in, like words, a photo or a file, and makes one kind of media. In 90 minutes they write one, run it, fix it after watching it fail, and post what it made to mime.ac.

The whole idea

inputs+prompt.md+a model→checks→one MIME type

That is Aesel's own idea at classroom size. Aesel always shows which kind of media you're making. A factory harness picks one kind, its output goal, and everything else follows from it: the file extension, the format rules the model gets, the checks the result must pass, and how the model's answer becomes a file.

Claude Code, Aesel and every other agent tool have the same parts, only bigger. When students write a prompt.md and a check.mjs, they are doing what the people who build those tools do.

A harness is a folder

my-harness/
  harness.json   { "name": "my-harness",
                   "inputs": ["text", "image"],
                   "output": "image/svg+xml" }
  prompt.md      what it knows and how it decides  ← the part students write
  check.mjs      optional: export default ({ text }) => [problems]
  runs/          every run: inputs, the model's full answer, the file it made

What happens when you run one

  1. 1

    Inputs are packed. Words go in as text. Photos (jpg, heic, png) become a PNG of at most 768 px. Text files are read in as words. An input the harness didn't list in harness.json is refused.

  2. 2

    The system prompt is built. The student's prompt.md comes first, then the format rules for the output goal, such as "one standalone SVG inside an svg block". The student writes the taste; the factory adds the format.

  3. 3

    AC hosted inference answers. It uses Claude Sonnet 5.5 by default and is paid in braincells on the student's own @handle. Nothing else needs installing.

  4. 4

    The answer is checked. Built-in checks for the type run first (the JSON parses, the SVG is complete, KidLisp's parentheses balance, the score plays), then the harness's own check.mjs.

  5. 5

    One repair round. If a check fails, the problems go back to the model and it gets one more try. The terminal shows repairing: ….

  6. 6

    The file is made in runs/<time>/output.<ext>. For most types the answer is the file. For PNG the model writes an image prompt and an image model paints it. For WAV the model writes a score and the laptop synthesizes it.

  7. 7

    ac harness post puts it on mime.ac, on the board for its MIME type, so the class's SVGs end up together and the WAVs end up together.

Six starters

Copy one with ac harness new my-copy --from <starter>, then change its prompt.md.

starterin → outwhat it does
haiku-camimage + text → text/plaina photo becomes a haiku about what's just outside the frame; its check.mjs requires three lines
postertext → image/svg+xmlan event becomes a Swiss-style typographic poster
zinetext + image + file → text/htmlthe multimodal one: notes, a photo and a file become a one-page web zine
humtext → audio/wava feeling or place becomes 8–16 bars of music
kidlisptext → text/x-lispa sentence becomes a KidLisp piece to paste into aesthetic.computer
stickertext + image → image/pngthe model art-directs and an image model paints a die-cut sticker

The 90-minute route

  1. 0:00

    Install and sign in · 10 min

    curl -fsSL https://prompt.ac/aesel.sh | sh
ac login
ac whoami
  2. 0:10

    Run someone else's harness · 10 min

    Everyone runs poster on their own event. Put three results on the projector. Same harness, same model, different posters: why?

    mkdir workshop && cd workshop
ac harness new poster --from poster
ac harness run poster "rooftop karaoke, friday, 9pm"
  3. 0:20

    Read a harness · 10 min

    A dry run prints exactly what the model is told and spends nothing. Show the seam: the student's prompt.md on top, the factory's format rules underneath.

    ac harness run poster "rooftop karaoke" --dry
  4. 0:30

    Change one thing · 15 min

    Edit prompt.md: a rule, a palette, a persona. Run it again and compare the two runs/ folders. Then pair up and run each other's harness.

  5. 0:45

    Make your own · 25 min

    Pick an input and output pair no starter covers. new writes a prompt.md outline with the inputs and goal filled in. Then try an input meant to break it.

    ac harness new receipt-poem --in image --out text/plain
ac harness new mood-chord   --in text  --out audio/wav
  6. 1:10

    Add a check · 10 min

    A check makes a harness stricter without retraining anything. Whatever it returns goes back to the model for one fix.

    // check.mjs
export default function check({ text }) {
  return text.length > 280 ? ["Keep it under 280 characters."] : [];
}
  7. 1:20

    Post and show · 10 min

    Each post lands on its MIME type's board. Walk the boards on mime.ac on the projector.

    ac harness post my-harness "a caption"

Before class

HandlesEvery student needs an aesthetic.computer account with a claimed @handle. Runs are paid in braincells on that handle; plan on about 20 runs each.
5 PNGs a dayimage/png goals use the hosted image model, which allows 5 images per handle per day. Demo sticker yourself.
Wi-FiTry a run on the room's network beforehand. A dropped connection is retried once.
What can go inWords and pictures only. No audio, video or PDF input yet; a file input must be text.
