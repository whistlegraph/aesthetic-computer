\section{Finding}

\noindent\colorbox{acpink!10}{\parbox{0.94\columnwidth}{\vspace{0.25em}\small
\textbf{The better concept name is \nameword{babypat}; the better public acquisition today is \nameword{bbswipe.com}.} Unfortunately, \texttt{babypat} carries both domain friction and an exact-name trademark collision in a technologically adjacent class. If a domain is to be secured now, \texttt{bbswipe.com} is the clean action. If the name should carry the product for years, it is worth one more naming round before committing publicly.\vspace{0.25em}}}

Porkbun reported \texttt{bbswipe.com} \textbf{available} at \money{11.08}, non-premium. It reported \texttt{babypat.com} \textbf{unavailable}. Verisign RDAP independently shows \texttt{babypat.com} was registered 2025-05-01, expires 2027-05-01, uses Afternic nameservers, and is registered through GoDaddy. The Afternic nameservers suggest a parked or resale posture, but that is an inference, not a sale offer.

\pull{the domain result reverses the naming result: babypat says the right thing; bbswipe owns the clean front door.}

\section{The Names Tried So Far}

\subsection{\texttt{cancelok}}

The ancestor. Its name expresses binary judgment: stay/tap is \emph{ok}; leave is \emph{cancel}. It fits evolutionary curation, but not the new educational or developmental loop.

\subsection{\texttt{vertilok}}

The implemented vertical, full-screen feed. It names its geometry and lineage well, but reads as infrastructure: a mechanism, not a child-facing destination. It remains useful as the architectural parent.

\subsection{\texttt{babypat}}

\textbf{Why it works:} affectionate, small-step, playable; sounds native beside \texttt{notepat}; can grow from touching into learning without a rename. ``Baby'' encodes beginnings, not necessarily babies.

\textbf{Why it breaks:} \texttt{babypat.com} is taken; search results already carry parenting, food, music, and MatPat associations. More seriously, a preliminary U.S. screen finds the exact mark \textsc{BABYPAT}, Registration 5,653,929 / Serial 87,911,102, in International Class 009 for electronic and audiovisual goods. That is not a legal conclusion, but it is enough to demand real clearance before a public software/learning brand.

\subsection{\texttt{bbswipe}}

\textbf{Why it works:} compact, ownable, internet-native, and the \texttt{.com} is available. ``BB'' can hold \emph{baby}, \emph{bulletin board}, or simply a rhythmic pair of letters.

\textbf{Why it breaks:} ``swipe'' promises that swiping advances the feed, while the proposed system advances on accumulated interaction or goal completion. The name points at the old gesture, not the new rule. It also feels more like a feed utility than a growing play-space.

\section{Recommendation}

\begin{enumerate}
  \item \textbf{Do not buy \texttt{babypat.*} merely to compensate for the missing \texttt{.com}.} The trademark and collision surface matter more than the extension.
  \item \textbf{If securing an option now is desirable, \texttt{bbswipe.com} is the rational registration.} It is available, standard-priced, and had no obvious exact-name collision in this preliminary web screen. Registration itself is not trademark clearance.
  \item \textbf{Keep \texttt{babypat} as the internal design brief, not yet the public brand.} It names the feeling we should preserve: tiny acts of play accumulating into advancement.
  \item \textbf{Run one more naming round around growth, completion, and play---not swiping.} The strongest eventual name should inherit \texttt{babypat}'s warmth and \texttt{bbswipe.com}'s ownability.
\end{enumerate}

\section{Product Contract to Preserve}

Whatever name wins, the mechanism should stay separable from its goals:

\begin{itemize}
  \item \texttt{progress = completed / required}
  \item today: \texttt{completed = active milliseconds}
  \item later: correct answers, words formed, notes matched, patterns finished
  \item idle: no gain, no loss, no automatic next
  \item completion: bar resolves, next piece slides upward, deck eventually loops or reshuffles
\end{itemize}

This contract is the conceptual invention. The feed is not measuring exposure; it is measuring participation.
