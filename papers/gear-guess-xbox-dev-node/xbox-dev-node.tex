\section{there is no 128GB Series S}

\begin{gearwarning}[128 IS A BUS, NOT A SMALLER SSD]
Microsoft lists three Series S configurations: Robot White with a 512GB custom
NVMe SSD, Carbon Black with 1TB, and Robot White with 1TB. The specification
also says \textbf{10GB GDDR6, 128-bit-wide bus}. That \emph{128-bit} line is the
likely source of a ``128GB'' memory. It describes the width of the memory bus,
not storage capacity. There is no official 128GB retail Series S edition.
\end{gearwarning}

The 512GB model is therefore the capacity floor for this generation. It is the
right floor for our job: Dev Mode packages, frame captures, test media, and a
small demo scene do not justify paying for 1TB. An external USB drive can hold
ordinary media later, but it does not make the console a cheaper model.

\begin{gearcard}{names that look close but are not the same machine}
\textbf{Xbox One S} is the previous generation and was sold with 500GB, 1TB,
and 2TB hard drives. \textbf{Xbox Series S} is the small current-generation
white console in this paper. Listings that say ``Xbox One Series S,'' omit a
model photo, or advertise 128GB should be treated as identification failures.
For the white 512GB Series S, ask for the rear label and confirm hardware model
\textbf{1883} before paying.
\end{gearcard}

\section{buy this}

\begin{gearcard}{today / Microsoft Certified Refurbished}
\gearprice{Xbox Series S 512GB}{\$329.99}
Microsoft says the unit is screened, repaired, tested, cleaned, repackaged,
and supplied with standard accessories. The Xbox warranty is 90 days. This is
the preferred purchase when the node needs to enter the deployment loop now:
the seller, condition language, box contents, shipping, and return surface are
all legible in one place.
\end{gearcard}

\begin{gearcard}{patient route / eBay used}
\gearprice{Tested model 1883, delivered}{\$250 maximum}
Recent eBay observations put ordinary working 512GB units around \$220--250
before tax once shipping is included. Use the current category shelf, not a
pinned item, because listings expire. Require actual photos, a power-on claim,
no console/network ban, no smoke or liquid history, a credible seller, and a
return path. Prefer controller + power + HDMI; console-only is acceptable at
\$225 delivered or less because we already own compatible input hardware.
\end{gearcard}

\begin{gearwarning}[THE FAKE FLOOR]
Do not use ``parts only,'' ``does not power on,'' ``USB port non-functional,''
or a live auction bid to establish the used price. A \$90 repair unit is not a
cheap node; it is a different project. Also reject a listing merely saying
``Series S used under \$150'' until the detail page proves it is the console,
working, unbanned, and not just a controller or shell.
\end{gearwarning}

\section{the other lanes}

\begin{gearcard}{Back Market / watch only}
Its US Series S page showed zero products during this check. An older search
index still showed a \$369.99 starting price; the live page outranks the stale
snippet. Back Market remains useful as a refurbished source, but it is not a
current offer.
\end{gearcard}

\begin{gearcard}{Amazon / currently upside down}
The official 512GB ASIN had no ordinary Amazon buy box. The page exposed other
new-and-used offers from \$433.49 and related Renewed offers from \$396.55.
Those are above Microsoft's certified price and fail the value test. ``On
Amazon'' is not the same fact as ``sold by Amazon.''
\end{gearcard}

\begin{gearcard}{1TB / wrong reason to spend more}
The 1TB Series S is a real model, but capacity does not change CPU, GPU, Dev
Mode, Device Portal, or our app sandbox. Buy it only if its delivered price is
equal to or lower than the comparable 512GB unit. Storage is not throughput for
this job.
\end{gearcard}

\section{day-one score}

\begin{gearcard}{before payment}
\gearcheck Confirm the rear label says model \textbf{1883} and the listing says
\textbf{Xbox Series S 512GB}, not Xbox One S.\par
\gearcheck Confirm it powers on, reaches Settings, connects to Xbox services,
and is not console-banned.\par
\gearcheck Confirm power cable, HDMI cable, controller status, seller feedback,
shipping, returns, and delivered price.\par
\gearcheck For eBay, save the listing page and photos with the dated offer
snapshot before checkout.
\end{gearcard}

\begin{gearcard}{first hour on the bench}
\gearcheck Factory-reset the console and install current system updates.\par
\gearcheck Activate retail Dev Mode; record the console name, serial, hardware
model, activation account, and Device Portal identity in the private fleet
inventory---never in the public paper.\par
\gearcheck Put it on wired Ethernet, reserve its address, and install the current
Xbox Native BIOS package.\par
\gearcheck Run the 60 FPS scene, input stream, frame-return path, audio clock,
and a 30-minute thermal/relaunch soak.\par
\gearcheck Only after the soak passes, call it a node and assign its fleet name.
\end{gearcard}

\begin{bestguess}[WHAT WOULD CHANGE THE GUESS]
An active, returnable eBay listing at or below \$250 delivered changes the
answer from Microsoft refurb to used. A Back Market unit below \$300 with a
strong warranty could become the middle lane. A 1TB unit at the same delivered
price beats 512GB harmlessly. No amount of misleading ``128'' labeling changes
the hardware floor: for Series S, 512GB is the smallest real internal SSD.
\end{bestguess}
