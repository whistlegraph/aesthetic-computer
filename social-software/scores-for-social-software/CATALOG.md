# Working media description

## Collection-level description

This archive documents two moments in the life of **Scores for Social Software**: the cohort's June 13 closing event at Fuser and a later July 16 documentation shoot. Together, the material moves between presentation, performance, interface demonstration, installation detail, gathering, and retrospective documentation. It should be mastered as an event archive with multiple authors and works, not as a single undifferentiated photo roll.

## SSF-20260613 — Fuser presentation

**Extent:** 78 JPEG photographs plus one 7m39.9s, 1920×1080 H.264/AAC video explicitly named for Chelly Jin.

**Identified context:** The official program describes a two-hour closing event at Fuser following a ten-week working group. Ten cohort works were presented. The still photographs use Pixel-style timestamp filenames spanning roughly 10:48–13:30 local filename time; their precise clock relationship and ordering need verification from embedded metadata.

**Initial description:** A multi-work gathering in which scores are presented through talks, performances, sound, interfaces, objects, and collective attention. The catalog pass should divide these images into presentation/work sequences and use the official program only as a candidate ordering—not assume every photographed person or work from appearance.

Contact-sheet review will establish shot groups, strongest frames, depicted actions, and the relationship between the long take and stills.
